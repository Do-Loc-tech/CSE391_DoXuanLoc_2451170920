# Weather App

API đã dùng:
- `https://wttr.in/{city}?format=j1`

Cách chạy:
1. Mở `weather_app/index.html` bằng trình duyệt.
2. Nhập tên thành phố và nhấn "Tìm".
3. Ứng dụng sẽ hiển thị trạng thái Loading, Success hoặc Error.

Chức năng:
- Tìm thời tiết theo tên thành phố.
- Hiển thị nhiệt độ, độ ẩm, mô tả và icon.
- Lưu lịch sử tìm kiếm 5 thành phố gần nhất vào LocalStorage.
- Click lịch sử để tìm lại.
