# User Directory

API đã dùng:
- `https://jsonplaceholder.typicode.com/users`

Cách chạy:
1. Mở `user_directory/index.html` bằng trình duyệt.
2. Chờ load danh sách user.
3. Thêm, sửa, xóa user và tìm kiếm theo tên/email.

Chức năng:
- READ: lấy danh sách user từ API.
- CREATE: gửi POST rồi thêm user lên UI.
- UPDATE: sửa thông tin user rồi gửi PUT.
- DELETE: xóa user với DELETE.
- SEARCH: lọc client-side theo name/email.
